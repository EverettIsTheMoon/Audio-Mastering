Audio & Video Mastering Studio

Batch process audio files and videos, master their sound, and export each file separately.

1. Select audio and video files

Can’t pick your files? Try this picker

This one shows every file type. Files that aren’t audio or video are ignored.

Video audio is extracted for mastering. Video export keeps the original footage and replaces its audio with the mastered version.

2. Mastering controls

Speed changes the audio duration and pitch. The limiter reduces peaks to help avoid clipping.

3. Cover art for audio-only videos

For audio files exported as MP4, the cover fills the background with a blurred enlargement and appears centered. Output is always a 1920×1080 landscape video.

You can also do this per video, and give any file its own cover image, in the file list in step 1.

YouTube treats videos that are square or vertical (and under 3 minutes) as Shorts. Converting makes them regular widescreen videos, but it re-encodes the footage, which is slower.

4. Batch export

Tick the files you want in step 1, then export them together.

Select some files to begin.










The test loads the encoder and reports whether it worked. The ZIP holds the encoder files (about 31 MB): unzip it so the ffmpeg folder sits next to this HTML page and it will load them from there instead of downloading each time.


Without the ZIP option, browsers may ask permission to allow multiple downloads. In the hosted version, WAV files are always delivered inside a ZIP. Video export uses FFmpeg.wasm. The first export downloads its encoder and may use substantial memory on a phone or VR headset.
